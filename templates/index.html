How to Run the Automated Test Suite (Windows PowerShell)
CLI Execution

Execute the full automated test suite using pytest with automatic HTML report generation and failure screenshots:

# 1. Run all tests in headless mode and generate self-contained HTML report
pytest tests/ -v --html=reports/report.html --self-contained-html
# 2. Run tests with visible browser window (headed mode for college viva demonstration)
pytest tests/ -v --headed --html=reports/report.html --self-contained-html
# 3. Open the generated HTML report directly in default browser
Start-Process "reports\report.html"
